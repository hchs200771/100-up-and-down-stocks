## 第三步：確定「涵蓋區間」

先用 Bash `date` 確認今天是星期幾。時間軸要涵蓋的是**上一個台股交易日收盤（13:30）到現在**這段空窗：

- 一般日：昨天 13:30 → 現在（含昨晚整個美股交易日）。
- **週一或連假後第一天：要往前涵蓋到上一個交易日（如週五）13:30，包含週六、週日發生的事**（週末常有央行官員談話、地緣衝突、關稅宣布、OPEC 會議）。

時間一律換算成**台北時間**，格式 `MM/DD HH:MM`。

挑 5–8 條寫進時間軸，**依時間由新到舊排**。判斷標準是「會不會影響今天台股開盤」，不是新聞有多熱鬧。找不到那麼多就少寫幾條，不要硬湊。

## 第五步：寫 `data/tmp/intl-events.json`（用 Write 工具）

```json
{
  "window": "09/04 13:30 → 09/05 05:00（台北時間）",
  "events": [
    {
      "when": "09/05 02:30",
      "cat": "央行",
      "title": "一句把事實講完的話，含關鍵數字",
      "impact": "利多",
      "level": "高",
      "chain": "一句影響鏈，例：油價→通膨→Fed 降息空間→台股估值"
    }
  ],
  "moverNotes": [
    { "symbol": "MU", "why": "為什麼漲跌的原因，一句", "tw": "南亞科、群聯、威剛" }
  ]
}
```

欄位規則：

- `cat` 只能是：`央行`、`數據`、`地緣`、`政治`、`關稅`、`財報`、`科技`、`原物料`。
- `impact` 只能是：`利多`、`利空`、`中性`——**站在台股的角度**，不是站在美股。
- `level` 只能是：`高`、`中`。高只給「今天開盤真的會反應」的事，最多 3 條。
- `title` 一句話講完事實（含數字），不要形容詞堆疊；`chain` 一句話講影響鏈，兩者都不要超過 40 字。
- `moverNotes` 的 `symbol` 要跟 `movers` 裡的完全一致（大寫），`tw` 是對應的台股供應鏈個股名稱（沒有明確對應就留空字串）。只寫查得到原因的，查不到就不要放。

## 第六步：寫 `data/tmp/intl-brief.txt`（用 Write 工具）

**字數硬上限：全文嚴格 300 字以內（中文字計），最多 3 段。** 這是盤後快訊不是長文，寫超過就刪到 300 字以內再寫檔。時間軸已經把「發生什麼事」講完了，這裡只寫**判讀**，不要重複條列事件。

1. 開頭一句帶過國際指數數字的重點（誰強誰弱、費半/美股隔夜、亞股當日）。
2. 挑最關鍵的 2 條大事（最多 3 條），每條用一兩句濃縮框架：定性「消息面 vs 傷基本面」+ 影響鏈 + 機率傾向（可用紅線：美10年殖利率 4.4–4.5%、油價 ~$100）。不要每條都展開成一大段。
3. 收在「對台股的意涵」：隔夜美股/費半、指標股與殖利率怎麼影響今日台股估值與電子權值，是順風還是逆風。

寫成**純判讀文字**（不要標題、不要 markdown、不要來源清單）。
