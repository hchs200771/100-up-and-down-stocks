# 全台股因子掃描結論（2026-10-03）

## 一句話

在完整六年全上市櫃資料上，17 條固定規則**沒有任何一條在多重比較校正後可靠地打敗基準**。上一版看好的「大盤站上 MA20 才進場」補齊資料後**轉為負增益**，不建議加進選股。唯一值得前瞻觀察的是「只買前 5 檔」的集中持股，但它同樣未達統計顯著。

## 這次做了什麼

- 補齊證交所（TWSE）缺的 533 個交易日：2026-10-02 那版只有 1,347/1,880 日，現在 TWSE 與櫃買（TPEx）都是 1,880/1,880 日（2019-01-02 至 2026-09-30）。
- 規則、門檻、成本都沒有調整，直接用同一份設定（`docs/factor-experiments-wide-config.json`）重跑。
- 可回測窗口從 30 個增加到 **81 個**（每 20 個交易日一期，2020-01 至 2026-09，零缺口）。
- 完整表格見 [factor-experiments-wide-results.md](factor-experiments-wide-results.md)。

## 測什麼

- 母體：每個訊號日當時的全部上市櫃四碼普通股（含後來下市者，2,084 檔），訊號日成交 ≥100 張。
- 基準策略：訊號日收盤後選 20 日報酬最強的 10 檔，隔日開盤等權買進、持有 20 個交易日。
- 比較對象：TAIEX 含息報酬指數。同期間指數累積 +366.6%，年化 27.1%，最大回撤 28.6%。
- 成本：買 0.1425%、賣 0.4425%，另跑買賣各 0.5% 不利滑價的情境。
- 統計：配對區塊 bootstrap 10,000 次，32 項比較做 Bonferroni 校正。

## 主要結果（81 期全樣本）

| 規則 | 有效期 | 打敗指數勝率 | 每期平均淨超額 | 對基準配對報酬差 | 滑價後超額 / 勝率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 基準：強勢前 10 等權 | 70/81 | 50.0% | +1.59% | — | +0.59% / 47.1% |
| **只買前 5 檔** | 77/81 | **55.8%** | **+2.98%** | **+1.27%** | **+1.98% / 53.2%** |
| 站上 MA20 且 MA20>MA60 | 70/81 | 48.6% | +1.72% | +0.13% | +0.72% / 47.1% |
| 避開除權息後 5 日 | 70/81 | 50.0% | +1.69% | +0.10% | +0.69% / 47.1% |
| 大盤 > MA60 才進場 | 75/81 | 52.0% | +1.40% | −0.38% | +0.71% / 49.3% |
| 大盤 > MA20 才進場 | 76/81 | 48.7% | +1.33% | −0.43% | +0.71% / 46.1% |
| 突破 20 日高 | 70/81 | 45.7% | +0.30% | −1.54% | −0.69% / 42.9% |
| 20 日漲幅 ≤25%（不追過熱） | 79/81 | 45.6% | −0.38% | −2.46% | −1.38% / 39.2% |
| 量增 1.5 倍且收紅 | 72/81 | 41.7% | −0.84% | −2.59% | −1.82% / 37.5% |
| 季底後半月才進場 | 78/81 | 29.5% | −2.80% | −4.66% | −2.91% / 29.5% |

「每期」是 20 個交易日。無效期多半是出場日一價到底（漲跌停鎖死、無法以合理價出場），或除權息參考價無法還原，這些期直接排除、不補值。所以連續年化（CAGR）無法計算，只能比較每期平均。

## 結論

### 1. 強勢股動能本身有正超額，但很薄

- 基準每期平均淨超額 +1.59%，但勝率剛好 50%：靠少數大贏期拉高平均，不是穩定贏。
- 加上 0.5% 滑價後只剩 +0.59%、勝率 47%。實際操作若追價成本較高，優勢可能幾乎被吃光。

### 2. 大盤 MA20 濾網：撤回

- 上一版只有 30 期時是 +1.97% 配對增益，補齊後變成 −0.43%。
- 2021、2024 年平均超額為負，主要是濾網讓部位空手，錯過指數反彈。
- MA60 與市場寬度濾網同樣是負增益。**不建議在選股池加任何大盤擇時開關。**

### 3. 不要過濾掉「漲太多」的股票

- 「20 日漲幅 ≤25%」在 2024–2026 驗證期配對報酬差 −5.14%，校正後 p=0.0064，是少數達顯著的結果。
- 意義：報酬主要來自最強的那幾檔，砍掉過熱股等於砍掉贏家。
- 這與先前乖離分層回測的結論一致：乖離大的股票勝率沒有比較低。

### 4. 只買前 5 檔：唯一值得前瞻追蹤的候選

- 開發期（2020–2023）+1.61%、驗證期（2024–2026）+1.12%，兩段同方向。
- 7 個年度平均超額全部為正（基準只有 5/7 年為正）。
- 但校正後信賴區間仍包含 0（p=1.0），而且集中持股的單期波動更大。**只當觀察假設，不直接改正式權重。**

### 5. 明確有害的條件

- 「突破 20 日高」與「量增 1.5 倍且收紅」：追當天爆量或突破的強勢股，平均超額顯著低於基準。
- 「剛除權息的股票」與「季底才進場」：都明顯落後。後者主要是因為多數時間空手，不是季節效應。

### 6. 成交 50 張 vs 100 張門檻：沒差

配對報酬差 +0.01%。母體放寬不會帶來增益，維持 100 張即可。

## 對每日報告的影響

- **終極選股池（`build-stock-picks.ts`）不需修改。** 目前沒有大盤濾網、沒有漲幅上限，正好避開了被證明有害的兩個條件。
- 法人力度（Z 分數＋佔股本比，見 [institutional-strength.md](institutional-strength.md)）不在這次測試範圍，因為沒有歷史全市場籌碼資料。門檻仍是未回測的預設值。
- 建議前瞻追蹤：每日選股池前 5 名 vs 前 10 名的後續 20 日超額，累積 6 個月後再決定是否集中。

## 限制

- 這是「20 日強勢股」獨立策略的檢驗，**不是營收＋毛利策略的回測**。營收策略的逐月歷史持倉仍未重建，這裡的結論不能直接套用到營收頁。
- 個股報酬用官方參考價做再投資近似，不是逐筆現金股利。
- 2020–2026 已是開發樣本（過去的研究都看過這段），沒有真正乾淨的樣本外資料；新規則只能用前瞻資料驗證。

## 重跑方式

原始逐日資料存在本機 `data/backtest/wide/`（約 155 MB，不進版控）；交易日曆與含息指數在 `research/wide-market/benchmark-input.json`。換電腦或資料遺失時，重新抓取即可（已存在的日期會跳過）：

```bash
npm run backtest:wide:actions        # 除權息／減資參考價
npm run backtest:wide:fetch -- --workers 1
npm run backtest:wide
npm run backtest:wide:render         # 產生 docs/factor-experiments-wide-results.md
```

證交所遇到大量請求時會回 HTTP 307/308/428（反爬蟲驗證頁）。看到就停止、等幾分鐘再用單一 worker 續抓，不要繞過。
