# 新選股因子研究判讀（2026-10-07 重跑）

本次固定規則沒有足夠證據支持增加正式選股因子，因此保留研究結果、暫不修改每日選股權重。未改善的實驗也有價值：後續研究可以直接沿用結果，或針對明確限制提出新的假說，而不用再次搜尋同一套條件。

這個結論只涵蓋以下代理模型、20日訊號窗口、交易規則與實際可用資料；不能宣稱原論文策略或整個因子家族都無效。

## 測了什麼

- 日間動能：最近20交易日的開盤至收盤對數報酬總和，高者優先。
- 隔夜反轉：最近20交易日的前收盤至當日開盤調整後對數報酬總和，低者優先。
- 日間＋隔夜反轉：前兩者的全候選母體百分位排名等權平均。
- 大盤殘差動能：先用252交易日估計「截距＋大盤beta」，再對後續20日的個股報酬扣除模型預測，以殘差總和／訓練殘差標準差排名。訓練與訊號期間不重疊。這是使用加權價格指數日報酬的簡化代理，沒有使用原論文多因子與月資料規格。
- 原始＋大盤殘差動能：原始20日報酬與殘差分數的百分位排名等權平均。

每個家族都與相同資料完整母體的原始20日動能前10檔比較；不能把不同家族的平均直接相減。這是獨立價格選股策略，沒有重建營收＋毛利策略的歷史持倉，也不是現行每日選股池的完整回測。

## 結果與決策

下表為雙方執行有效的同期配對平均淨報酬差，單位是**百分點／期**；已扣買賣成本。正數代表勝過同家族基準，不代表勝過指數。

| 新規則 | 持有2日 | 持有5日 | 持有20日 | 本輪判斷 |
| --- | ---: | ---: | ---: | --- |
| 日間動能 | 0.00 | −0.03 | −1.19 | 未見改善，暫不採用 |
| 隔夜反轉 | +0.21 | −0.05 | −2.47 | 增益不一致，暫不採用 |
| 日間＋隔夜反轉 | +0.05 | −0.43 | −1.27 | 未見改善，暫不採用 |
| 大盤殘差動能 | −0.09 | −0.30 | +0.12 | 與原始動能無差異，暫不採用 |
| 原始＋大盤殘差動能 | −0.04 | −0.23 | −0.03 | 與原始動能無差異，暫不採用 |

沒有新規則在90項比較校正後同時得到正的配對增益與可靠統計支持；90項比較的校正p全部是1.00。補齊行情後，配對期數約為10/05首輪的兩倍（2日約650～730期、20日約55～71期），結果反而更貼近零：首輪20日「日間＋隔夜反轉」的+1.54百分點變成−1.27，殘差代理的−4.18變成+0.12。首輪的較大數字主要來自小樣本雜訊。

2日持有期中，各新規則在各自有效窗口的平均淨超額報酬均為負（約−0.4～−0.9%／期），增加買賣各0.5%不利滑價後更差。殘差代理現在有2024–2026的可評估窗口，前後兩段的配對增益都接近零，沒有「近期轉強」的跡象。

完整分期表、勝率、配對期數、校正區間與滑價情境見 [完整結果](novel-factor-backtest-results.md)。精簡數字快照見 [2026-10-07 研究快照](../research/novel-factors/2026-10-07-summary.json)；首輪（有行情缺口）快照保留在 [2026-10-05](../research/novel-factors/2026-10-05-summary.json)，可比對。

## 資料與交易規格

- 全市場歷史上市／櫃買四碼普通股票行情母體，沿用既有全市場引擎，不以今日仍上市名單回填過去，包含後來下市的代碼。
- 行情範圍2019-01-02至2026-09-30，共1,880交易日、2,084歷史代碼；訊號起點固定2020-01-02。
- 10/05首輪時工作區缺466個TWSE交易日（補抓遭證交所HTTP403拒絕）。之後這些日檔已補齊，10/07以同一份固定規則重跑時上市、櫃買都沒有缺日。
- 訊號日成交至少100張，並符合原61日指標暖機。拆解要求21日真正成交資料；殘差要求273日真正成交資料。停牌、缺OHLC、未解除權息價格段落不補零，也不當成通過。
- 收盤後形成訊號，隔日開盤等權買入前10檔，持有2／5／20交易日，各自固定調倉phase，期數不重疊。2日是隔日開盤至再隔日收盤，跨過一夜；**沒有回測當沖，也不是尾盤買、次日開盤賣的純隔日沖策略**。
- 每期完整換倉。買費0.1425%、賣費0.4425%；另測買賣各0.5%不利滑價。失敗進場留現金，無法合理出場或持有期間價格單位未解的期數標無效，不事後替換股票。
- 比較同窗口加權含息指數，並配對同家族原始動能。仍有停牌、無法出場等執行缺口，因此不拼接出完整連續CAGR與最大回撤。
- 時間區塊bootstrap 10,000次。2／5／20日策略分別用30／12／3期區塊，約60交易日；不跨不連續配對段落。五條新規則×三持有期×報酬及勝率兩指標×三報告期間，共90比較校正。
- 2020–2026已被本專案研究使用；2024–2026只是事後期間穩定性檢查，**不是乾淨樣本外**。沒有因看到結果而調門檻或挑選最佳窗口。

拆解的2／5／20日完整行情窗口分別818／327／81期；殘差分別803／321／79期（首輪為405／159／37與189／75／18）。這些是行情可形成窗口，執行有效期更少。無效執行可能非隨機，不能把有效窗口平均視為整段六年的可實現報酬。

## 尚未驗證的候選

| 候選 | 狀態與必要資料 |
| --- | --- |
| 毛利／總資產 | 未回測。需完整歷史TTM毛利、總資產、當時公告時間與財報版本；現有近期損益快照沒有總資產。不能將資料不足記成方法失敗 |
| 產業調整短期反轉 | 未回測。需歷史產業成分與事先固定的產業調整規則；本輪隔夜反轉不等於此因子 |

| 分析師盈餘預估上修 | 未回測。需有時間戳的歷史預估、上修／下修人數與覆蓋名單 |
| 研發投入／市值 | 未回測。需歷史研發費用、市值、公告時間與產業可比性 |

行情缺口已補齊並以原規則重跑，結論不變。若後續要繼續，需要的是財報時點資料（才能測上表的基本面因子），或累積2026-10之後的乾淨前瞻樣本；不要對本輪規則調參。新的窗口、多因子殘差或純隔日沖屬新實驗，需要另外固定規格並與本輪分開記錄。只有補資料、增加乾淨前瞻樣本或提出不同的事先假說，才足以重新評估正式採用。

## 重跑與檔案

```bash
# 本機需已備妥全市場行情和公司行動快取
npm run backtest:novel

# 驗證
npm run lint
node --import tsx --test tests/novel-price-factors.test.ts tests/novel-factor-backtest.test.ts tests/expanded-backtest-features.test.ts tests/backtest-wide-market.test.ts tests/wide-market-panel.test.ts
```

輸入：`data/backtest/wide/daily/{twse,tpex}/*.json.gz`、`data/backtest/wide/actions/twse-ex-references.json`、`research/wide-market/benchmark-input.json`。公司行動參考檔雖名為twse，沿用既有引擎的整合參考資料。資料抓取方式見 [既有全市場研究](wide-market-scan-conclusion.md#重跑方式)；遇到官方拒絕存取就停止。

規則：[novel-factor-backtest-config.json](novel-factor-backtest-config.json)。實作：`scripts/backtest-novel-factors.ts`、`scripts/lib/novel-price-factors.ts`。完整JSON在 `data/backtest/novel-factors/results.json`，含逐期持倉、失敗進場、無效出場與覆蓋率；此目錄被git忽略。完整Markdown、研究判讀、固定規則與精簡JSON快照放在版控可追蹤目錄，讓後續研究者不需原始快取也能讀取本次結論。

參考：[台股日間／隔夜報酬拆解](https://doi.org/10.1016/j.pacfin.2023.102151)、[殘差動能](https://www.sciencedirect.com/science/article/pii/S0927539811000041)、[毛利／總資產](https://mysimon.rochester.edu/novy-marx/research/OSoV.pdf)。
