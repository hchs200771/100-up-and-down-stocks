# 全市場因子研究接續說明

這版是可重跑的研究檢查點。程式、公開資料快取與實際結果都包含在 Git，沒有修改正式選股權重或寄送報告。

先讀 [成果摘要](factor-review-2026-10-02.md)、[完整結果表](factor-experiments-wide-results-2026-10-02.md) 與 [資料稽核](wide-price-data-audit-2026-10-02.md)。原成交額前60檔只是已淘汰的試跑範圍；正式研究使用歷史逐日上市櫃四碼股票，含四碼TDR、外國與創新板股票，排除ETF、權證及興櫃。

## 回家重跑

在專案根目錄，依序執行：

```bash
git pull --ff-only
npm run backtest:restore
npm run backtest:wide
npm run backtest:wide:render
```

若此機器尚未安裝套件，先執行 `npm ci`。需要 Node.js、Python 3（標準函式庫 gzip/lzma/tarfile），研究程式不需 Python 第三方套件。

`backtest:restore` 會驗證資料封包 SHA-256，將快取與原始結果還原到不進版控的 `data/backtest/`。當前封包約70MiB，所有新增研究輸入約75MiB；`research/` 僅保存此次固定檢查點，重新回測的輸出在 `data/backtest/wide/results.json`。

## 資料現況

- 2019-01-02至2026-09-30的TAIEX交易日共1,880日；TWSE取得1,347日、TPEx取得1,880日。TWSE缺533日，最後收到HTTP403、官方WAF阻擋，已停止請求。
- 全部已取得的歷史母體共2,084個代碼；每個可測訊號日先按當日50/100張過濾，再用當時價格選強勢股票，不用今日強勢名單倒推。
- 81個預定20日訊號窗口中，30個的61日暖機及20日持有資料皆完整。其餘51個沒有納入，不代表空手，也不代表沒有股票。
- 可測窗口落在2020年、2023年、2025年與2026年。2024–2026時間驗證區實際只有2025/2026的13期；不能稱為完整三年驗證。
- 17條固定規則已執行。未解價格段或出場行情會使該期無效；買不到則保留現金。間斷窗口不能計算整段連續CAGR。
- 個股報酬是官方參考價調整的再投資近似，並非逐筆現金股利與實際成交損益。交易成本已計入，另有買賣各0.5%不利滑價情境。

## 下一步

先補TWSE的缺日期，再重跑同一套規則，不調整門檻。能正常存取官方網站時執行：

```bash
npm run backtest:wide:fetch -- --workers 2
npm run backtest:wide
npm run backtest:wide:render
```

下載會沿用有效快取，僅補缺日；HTTP403或429會停止新請求，不繞過阻擋。補齊後需重新確認可測窗口數、無效持倉與配對樣本數，才評估連續績效。官方公司行動參考價已封裝；如需重建可執行 `npm run backtest:wide:actions`。

目前大盤MA20是值得優先繼續驗證的候選：全樣本同日配對24期，每期淨報酬差約+1.97百分點、打敗大盤機率差+8.33百分點；32重比較校正後仍不能證實可靠增益。2025/2026同日配對僅10期，改善勝率只相當於多贏一期。50張母體比100張更寬，但沒有已確立的報酬增益。不要依這一版直接改正式策略。

營收＋毛利策略的原始逐月名單與point-in-time資料仍未取得；這輪是獨立強勢股策略的價格／市場／事件實驗，不能把增益直接等同於疊加到營收策略的效果。
