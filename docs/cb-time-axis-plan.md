# CB 時間軸訊號計畫

> 目標：把「可轉債的時間大數據」加進 CB+設質 screener（`scripts/screen-cb-pledge.ts`），先以標記上線、回測後再決定是否進評分。
>
> 撰寫日期：2026-10-12。尚未實作，也尚未回測。

## 來源與要驗證的說法

來源是一篇社群文章〈可轉債大數據：主力派對什麼時候開始？〉，提出兩條規律：

1. **上市 3–6 個月是開盲盒，沒成的一年後才是啟動點。** 文章稱 CB 在「上市一年後」與「到期前一年」有明顯的異常報酬；上市 3–6 個月內沒動，通常就不會動。
2. **賣回日後的公司起手勢。** 賣回日過了、投資人仍未轉換、股價離轉換價不遠，公司通常會做多表態。這時常剛好是到期前一年，若股價開始動、又有題材配合，而且 CB 價格不貴，期望值高。

文章說「根據統計」「勝率極高」，但沒有附資料來源。以下所有規則都要先回測（見 Phase 2），不能直接當成有效因子。

另外，`docs/factor-review-2026-10-02.md` 裡「CB+設質訊號」只有 3 個樣本、平均 −3.81%，目前證據偏弱，這也是先做標記、後調評分的原因。

## 目前策略的缺口

評分（`scoreCandidate`）由四塊組成：

| 分項 | 配分 |
|---|---|
| 股價相對轉換價的位置 | 0–35 |
| 轉換進度 | 0–25 |
| 董監設質 | 0–25 |
| 可執行性（流動性） | 0–15 |

另有「突破轉換價+MA20」加 5 分。時間面只判斷「轉換期過了沒」與「轉換期未開始」。

CB 資訊看板 CSV（`fetchCbBoard`）其實已經有時間欄位，只是解析時沒存：

- `f[6]`／`f[7]`／`f[8]`：最近賣回權起日、迄日、價格
- `f[12]`：終止櫃檯買賣日（約等於到期日）
- 發行日：看板沒有，用「轉換起日往前推 3 個月」估算（台灣 CB 一般發行滿 3 個月才能轉換）。若之後找到含發行日的 TPEx 資料，改用實際值。

另一個觀念上的缺口：這套邏輯真正的核心是「到期前一年、價格接近 100 的 CB 有到期保底」，也就是買 **CB 本身** 的下檔有限、上檔有轉換空間。目前 screener 只排現股，沒有 CB 端的報酬結構。

## Phase 1：screener 加時間軸標記（不動評分）

改 `scripts/screen-cb-pledge.ts`，評分公式不變。

### 1. 解析並保存時間欄位

- `CbInfo` 加 `putStart`、`putEnd`、`putPrice`、`delistDate`、`issueDateEst`。
- `BondView` 與輸出的 `bonds[]` 一併帶出，HTML 表格可加一欄「階段」。

### 2. 每檔 CB 的發行階段

以 `issueDateEst` 和 `delistDate` 計算，依序判斷：

| 階段 | 條件 |
|---|---|
| 閉鎖期 | 發行未滿 3 個月 |
| 盲盒期 | 發行 3–6 個月 |
| 冷卻期 | 發行 6–12 個月 |
| 到期前一年 | 距到期 ≤ 12 個月 |
| 滿一年後 | 其餘 |

### 3. 三個新標記

- **盲盒落空**：盲盒期（發行後第 3–6 個月）現股最大漲幅 < 門檻（先用 +10%，回測再調），而且期間沒有站上轉換價。需要 Yahoo 日線回補該段股價；`data/cache/` 已有 RRG 的 Yahoo 快取可參考。
- **一年後啟動**：階段為「滿一年後」或「到期前一年」，並且出現啟動訊號：現有的「突破轉換價+MA20」，或帶量創 20 日新高（量 ≥ 20 日均量 1.5 倍，門檻待回測）。單純滿一年沒有篩選力：2026-10-12 的資料中，302 家公司裡有 152 檔 CB 屬於「滿一年後」。
- **公司起手勢**：以下全部成立
  1. 賣回日已過，或該檔沒有賣回權
  2. 已轉換比例 ≤ 30%
  3. 股價相對轉換價在 −15% 到 +5%
  4. 距到期 ≤ 12 個月
  5. CB 價 ≤ 110
  6. 現股站上 MA20

  文章的「有題材配合」先不自動化；之後可對照 KOL 分頁的 `tickers` 或新聞，當作附註而不是條件。

### 4. CB 端報酬結構欄

每檔 CB 加兩個數字，讓人直接比較「買 CB」的風險報酬：

- **到期保底報酬**：(到期或賣回可拿回的價格 − 現在 CB 價) ÷ CB 價。賣回價優先用 `putPrice`，否則用 100（面額；有補償金的再修正）。
- **轉換上檔**：股價回到轉換價時，CB 轉換價值相對現價的漲幅。

### 驗收

- `npm run lint` 通過。
- `npx tsx scripts/screen-cb-pledge.ts --force` 跑完；`data/cb-pledge-latest.json` 的每檔 bond 都有新欄位，抽查 3 檔的日期和賣回價與 TPEx 看板一致。
- 現有評分結果與改版前完全相同（同一天資料比對 `score`）。

## Phase 2：回測兩條規律

新增 `scripts/backtest-cb-time-axis.ts`，結果寫 `docs/cb-time-axis-backtest.md`，格式比照現有的 `docs/*-backtest.md`。

### 資料

- **要包含已到期與已贖回的 CB。** 看板只列仍在交易的債，直接拿來回測會有倖存者偏差。需要從 TPEx 找歷史發行資料（發行日、轉換價歷程、賣回日、到期日、實際下櫃日），至少涵蓋 2018 年後。
- 現股日線用 Yahoo，CB 日價格可用 TPEx 每日行情（`rsta0113`）回補，只取得到的區間做 CB 端分析。
- 所有條件只用訊號日當時已知的資料（轉換價用當時有效值，不用今天的值）。

### 要回答的問題

1. **時間窗口的異常報酬**：以發行日為事件日，算各月份（第 1–60 個月）現股扣大盤的平均報酬，看第 12 個月後與到期前 12 個月是否明顯高於其他時段。
2. **盲盒落空**：盲盒期沒動的 CB，第 6–12 個月與第 12 個月之後的報酬，跟有動的比較。
3. **一年後啟動**：訊號隔日開盤進場，持有 20／60 日，扣大盤、扣成本（來回約 0.585%）後的勝率與期望值。
4. **公司起手勢**：同上，另外算「買 CB 持有到到期或賣回」的報酬分布與最大回撤，驗證下檔是否真的有限。

### 判斷標準

- 樣本數至少 30 個事件才下結論；不足就標「樣本不足」。
- 扣成本後期望值為正、且分年度不只靠單一年度撐起來，才在 Phase 3 加進評分。

## Phase 3：依回測調整評分（視結果決定）

- 有效的標記才轉成分數，例如加一個 0–15 的「時間分」，並重新分配其他分項的配分，總分維持 0–100。
- 無效的標記保留為參考資訊或移除，並在本文件記錄結論。
- 評分改動後，比照 `docs/multifactor-roadmap.md` 的做法，持續累積前瞻報酬來追蹤。
