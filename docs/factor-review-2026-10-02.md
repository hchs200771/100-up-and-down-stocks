## 先釐清目前策略

營收策略在 `data/site/revenue.html`，與 `scripts/build-stock-picks.ts` 的每日長短線評分是兩套系統。後者沒有讀取營收頁面的數據。不能把其中一套的回測優勢當成另一套權重已經有效。

營收頁面現行預設完整條件是：

1. 月營收 YoY ≥20%。「YoY 連三月」指連三月年增率皆為正，不是年增率連三月加速。
2. 連三月 YoY 正成長，而且營收創近24個月新高（「核心」）。
3. 最新可用單季毛利率高於上一季。
4. 股價站上 MA20。

營收頁面另排除當月營收不足1億元、去年同月不足3000萬元、建材營造與創新板；頁面自述二月合併一、二月營收、一月回測跳過。這些是頁面記載，產生程式缺失，尚不能逐股核對實作。

| ID | 與B相比的唯一變動 | 需要資料 | 為何優先測 / 成功判準 |

## 正式回測規格

- 寬市場測試的母體固定為每個歷史交易日當時TWSE與TPEx資料列中的全部普通股（代碼符合四位數且首位非0），包含當時已上市櫃、後來下市的股票。不得用今天仍上市的名單反推歷史，也不得先找出「今天強勢股」再回選其歷史表現；歷史某訊號日當下的強勢股可以依預先固定規則入選。上市、上櫃與後來下市狀態依各日原始市場資料重建。
- 每日歷史價格抓取保留全體合格普通股列，包含成交量為0、低於50張或100張，以及個別OHLC欄位為0 / 缺值的列。成交量≥50張與≥100張是兩個待比較的**訊號日選股條件**，只能在選股時套用；不能在下載或建立歷史母體時先刪低量股票，否則會改變樣本與因子排名。
- 技術因子採至少61個交易日的暖機資料；暖機日只用來計算訊號，不納入可交易訊號日的績效。這是因子窗口需求，並非對股票的額外篩選。每個股票訊號需在當日資料足夠時才計算，缺資料明確列為不可評估，不補成零或「通過」。
- 先重現B的完整逐月名單和已發布數字，再改任何條件。所有策略共同月份配對；有效月份不足時報告淘汰 / 未形成組合月份，不能各用不同分母直接比平均。
- 訊號日收盤後形成名單，下一交易日開盤入場；若使用當日收盤形成MA20，不能同日收盤成交。原頁11日買的精確成交時點待核對。
- 同時對照加權指數與可投資普通股等權基準；剔除產業、市值、beta等暴露後再判斷因子增益。
- 月營收與財報用當時可知版本，處理更正；股數、產業、下市櫃 / 停牌 / 公司行動要留歷史。期限後使用財報只是代理，不能保證今日資料沒有歷史更正。
- 過去已用2020-08至2026-07搜尋288組，這段整體都是開發樣本；重切前後半不是乾淨樣本外。既有期間用於重建與探索，新資料凍結規則前瞻驗證。若能取得從未參與搜尋的更早期間，另外標示檢驗；不能為滿足樣本外而把已看過的月份改名。
- 報告每月淨超額勝率、每筆交易淨勝率（兩者分開）、平均 / 中位淨超額、盈虧比、期望值、最大回撤、換手、保留率、股票數、月份數、成本與容量。沒有逐日持倉不算組合最大回撤。
- 配對月增量報酬採時間區塊bootstrap信賴區間；股票 / 月份聚類，處理重疊持有；預定候選做多重檢定校正，不拿最漂亮的單次p值上線。勝率提升必須在預定指標上有證據，且淨期望值、回撤與有效樣本沒有實質惡化。
- 固定全額月換倉0.585百分點只作敏感度假設，正式結果按實際換手、買賣費用 / 稅率、滑價與可成交性逐筆計算；部分留倉不得每月重扣全部成本。

這部分是歷史摘要的重算，**不是新增濾網回測**。HTML報酬四捨五入到0.01%，重算與頁面的最後一位可能不同。IR採樣本標準差；頁面原始分母未保留，並沿用其√12年化慣例，沒有把跳過一月解讀成全年持續曝險。

### 寬市場歷史實驗範圍（待執行）

新的研究輸入以逐日市場資料建立全上市櫃普通股母體，並以每日成交至少50張、至少100張各自作為訊號日濾網。可納入某歷史日期當下符合規則的強勢股；不允許從今日贏家名單倒選其過去樣本。母體包含後來下市股，避免只以今日存續公司形成倖存者偏差。抓取資料不套成交量門檻，保留低量與缺報價列，成交門檻只在訊號形成時判斷。

指標計算至少載入61個前置交易日，作為MA60等窗口的暖機；只有暖機完成後的訊號日進入績效統計。這是技術因子的計算需求，不等於排除上市未滿61日的公司：其因子值應標記缺資料並按事先規則處理。寬市場第一輪可用窗口已完成，詳見本文件頂部連結；50張擴大母體，但目前沒有已確立的報酬增益。完整長期間仍有來源缺口。

### 實際補抓與每日選股濾網回測

新增可重跑命令：

```bash
npm run backtest:picks:fetch
npm run backtest:picks
```

第一個命令按現有歷史快照股票下載2026-07-01至09-30日價、法人與公司行動，寫到研究專用`data/backtest/price-input.json`，沒有覆蓋每日行情檔；第二個命令寫出`data/backtest/pick-filter-results.json`。已取得49檔個股加TAIEX，共3150筆日價、15420筆法人記錄，三項公司行動資料查詢全部成功。

在取得後續報酬之前固定比較：原榜、站上MA20、當沖≤35%、20日報酬>0%、20日報酬≤25%、有外資連買訊號、無CB+設質訊號。只讀訊號日快照，缺因子時篩除並統計，沒有以今日值回填。

其後另外新增三項探索：投信連買3日、投信5日累計淨買>0、20日均成交額≥5000萬。這三項從歷史原始資料計算，每個窗口嚴格要求TAIEX過去3/5/20個交易日（含訊號日）全部資料齊全，只看訊號日及以前；零值保留、缺值篩除，沒有搜尋最佳天數或門檻。

進場固定訊號後下一個TAIEX交易日開盤，持有5/10/20個交易日（進場日算第一日）於收盤出場，個股與加權指數使用同起訖時點，每筆扣0.585百分點。買進 / 賣出零量、無價或一字鎖住、訊號日價格不符、歷史缺價均列失敗原因，不偷移到下一個有價日。持有期間若跨除權息、減資、分割則篩除，以免未還原股價扭曲價格報酬；這會引入樣本篩除偏差，不能推廣到所有股票。特別核對六角09-03除息，未把這個機械跌價當策略損失。

這是「原榜股票在附加濾網下的固定持有表現」，不是重建全市場候選池，也不是營收B基準的增量實驗。原文字策略的等待MA10、突破進場與停損也尚未重現。四個訊號日集中在同一週、持倉重疊，不把數十筆記錄當數十個獨立期間；20日未成熟樣本另列。此輪只能提供候選線索，不能依最佳行自動改生產策略。

接續的寬市場回測改用每日動態普通股母體，包含歷史當日強勢股與後來下市股；以50張和100張成交量門檻在訊號日分別選股。此設計不把當今強勢股名單倒灌歷史，也不在抓取時按成交量刪列。研究已執行並提供可還原的資料檢查點；本節四日結果與寬市場30個完整來源窗口的結果分開記錄，詳見完整結果表。

下一輪可先追蹤「投信5日累計淨買」與「短線避免20日漲幅>25%」兩個候選，但目前沒有足夠資料將其中任一項判為可靠增勝率濾網。流動性是成交風險限制，此輪不支持把它當成提高報酬的alpha。法說事件與營收基準增量尚未實測，不用產業直覺替代結果。
