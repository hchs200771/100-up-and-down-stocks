# 同星期價平合與最大未平倉：研究結論

**同星期比較是合理的校正方式；相對偏高值得當風險背景追蹤，但沒有證實偏低代表即將爆發。最大未平倉區間有一定涵蓋率，這次沒有證實其履約價位置提供額外支撐壓力效果。**

## 價平合怎麼比較

使用當週週三到期的價平買權＋賣權；第三個週三使用當週到期月選，排除週五選。先以合價除以指數水準，再與**當天之前52筆同星期、同剩餘日曆天數**的平均相比，至少26筆才判斷。當天不進入自己的基準。例如週二、剩一天，就與歷史週二、剩一天比較；不拿週二與週一或結算日直接比較。

除以指數水準是為了避免指數從一萬多漲到兩萬多點後，僅因同樣百分比風險對應更多點數，就被判成風險暴增。這仍是權利金代理，並非精確隱含波動率或VaR。

固定平均比≥1.5為高、≤2/3為低。2019–2022為開發期，2023–2025為時間驗證期；以下是驗證期結果。「三日大行情」指訊號收盤後三個交易日內，指數最高或最低偏離訊號收盤至少2%，不分方向。

|價平合狀態|訊號日數|三日大行情：訊號日|三日大行情：其他日|
|---|---:|---:|---:|
|同星期平均的1.5倍以上|54|72.22%|38.77%|
|同星期平均的2/3以下|56|30.36%|42.38%|

這張表涵蓋各星期，且每一天都只和自己的星期及到期天數比較。只看週二時，高檔11次的三日大行情率72.73%，對照43.18%；低檔16次為37.50%，對照46.46%。週二樣本不足20個，不作穩定勝率推論。

偏高訊號與後續波動的關係值得繼續追蹤。但控制過去20日波動、當天漲跌及盤中振幅，再校正14個主要比較後，主要估計區間仍包含零；改變區塊長度會改變顯著性。高檔又集中在2024/2025，加入同年度對照後，只剩21個可匹配高檔訊號，估計區間更寬。因此尚未確認它在市場已發生的波動以外，還有穩定的預警增益。

**低檔不能直接解讀成行情醞釀。** 低檔後轉強值得另立假說，但本次「上週低檔，本週同星期合價／指數增加至少25%」只有7次，沒有足夠證據。單純同星期增加25%的75次觀察，三日大行情率56.00%，其他日38.31%；這只是探索性結果，不取代主要規則。

## 最大未平倉能不能當區間

定義下界為同到期賣權最大OI履約價、上界為買權最大OI履約價。使用**週二一般盤結束後可知的OI**預測週三，沒有偷用週三資料。夜盤不另公布未沖銷契約量，故「週二晚上看」實際使用的是週二一般盤OI；夜盤行情也不能與隔日一般盤資訊混合。

2019–2025共有341個正常週二→週三結算案例，假日順延20期排除。主要時間驗證使用2023–2025的143期：週選109、月選34。逐日下載官方現貨指數5秒資料，排除09:00:00的前日收盤值，每天3240筆；開高低收與既有日資料交叉核對，並以301筆結算窗口樣本平均核對官方最後結算價。

|週三結果（143期）|最大OI區間|同寬、以週二收盤為中心|
|---|---:|---:|
|全天高低都在內|56.64%|62.94%|
|超過一半盤中時間在內|75.52%|81.12%|
|收盤在內|72.03%|74.13%|
|最後結算價在內|70.63%|73.43%|

最大OI區間中位寬度約指數的2.37%，本來就不窄。相同寬度的對照用OI區間寬度，因此這個比較只測**履約價位置的額外效果**，沒有證明OI寬度本身毫無資訊。所有主要配對比較都沒有可靠的正向增益；改成只找價外最大OI也沒有改善結論。

週選的大部分時間涵蓋率77.06%、月選70.59%；全天守住則56.88%、55.88%。月選僅34期，不能據此宣稱兩者差異穩定。

有一個容易誤判的聯合現象：價平合位於歷史最高一成時，OI區間全天守住率69.57%；最低一成時只有41.38%。但兩組OI區間的中位寬度分別約指數5.04%與1.71%。**高風險時區間更寬，可能反而更容易涵蓋當日；高涵蓋率不能直接佐證大戶防守。** 此切片只有23與29期，屬描述。

## 開盤突破後會不會壓回

僅計算週二收盤原本在區間內、週三開盤才跨出去的「新突破」。碰回界線、收回區間與反向交易獲利分別計算。

2023–2025開在上界以上4次，只有1次盤中碰回，**0次收回區間**；開在下界以下4次，1次碰回、1次收回。樣本小，但沒有支持「突破就必然拉回」的證據。

例如2025-06-25，上界22300，指數開22341.87、盤中低22284.52、收22430.61：確實曾碰回區間，最後仍收在外面。2025-09-10上界25000，開25032.88，當日最低也是25032.88，收25192.59，整天沒有碰回。

把2019–2022也納入描述，上破15次中8次碰回、4次收回；下破11次中7次碰回、4次收回。從開盤逆勢持有至收盤的平均現貨指數報酬，上破做空約−0.30%、下破做多約−0.20%。這不是期貨可成交回測，沒有基差、成本或停損，也不足以建立順勢策略；但不能拿「曾碰回」當作逆勢操作勝率。

## 為什麼大戶防守假說不能直接成立

每一口OI同時有買方與賣方，口數本身不能辨認誰是大戶、裸賣、價差部位，或有沒有期貨避險。[OCC的OI說明](https://www.optionseducation.org/referencelibrary/faq/general-information)支持這個基本限制。即使確有大量賣方，避險也未必會把價格推回：淨短gamma的避險可能在上漲時買入、下跌時賣出，反而放大走勢。[Cboe對gamma與避險的說明](https://www.cboe.com/insights/posts/volatility-insights-evaluating-the-market-impact-of-spx-0-dte-options/)來自美國SPX，只用來說明機制可能雙向，不能當成臺灣OI區間的實證。

本次較合理的用途，是把同星期正規化價平合當成**待驗證的風險背景**，把OI區間當成**需觀察實際價格反應的參考**。尚不支持只憑低合價等待爆發，或在開盤突破最大OI後立即逆勢交易。價格偏高也不保證買跨式獲利：權利金可能已反映波動，本次沒有驗證選擇權交易報酬。
