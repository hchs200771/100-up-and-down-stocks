# Wide price and corporate-action data audit (2026-10-02)

This is a local-cache audit of price/reference inputs, not a strategy-performance review. It compared `data/backtest/expanded/expanded-input.json` for its 60 stocks with the cached TWSE/TPEx daily files and the downloaded official event tables. No network requests were made.

## Coverage snapshot

The wide daily cache contains 3,227 date files from 2019-01-02 through 2026-09-30: 1,347 TWSE dates and 1,880 TPEx dates. The manifest requests 1,880 exchange dates; 533 TWSE dates have no daily file in this snapshot. This means some apparently missing event-day comparisons below are cache gaps, not evidence that the event lacked a quote. The 60-stock expanded file has complete FinMind price/action fetch status, but that does not fill missing wide-source dates.

The consolidated TWSE event-reference file contains 12,389 rows, including ordinary ex-right/dividend events, 181 capital-reduction events, and 35 face-value changes. The expanded 60-stock action set contains 493 DividendResult events, 6 capital reductions, and 2 face-value changes.

## Cross-checks

Of the expanded actions whose event date has a corresponding wide quote, 376 DividendResult rows and 4 capital-reduction rows had a matching official reference row. All 380 had `before` and `reference` values with no difference greater than NT$0.011 from the expanded FinMind before/after values. The other 117 DividendResult dates and 2 reduction dates lack an event-date quote in the current TWSE cache. Neither of the two expanded face-value-change dates (6415 on 2022-07-13 and 2327 on 2025-08-25) is covered by a TWSE daily file, so their price continuity is not independently validated against wide OHLC here.

TPEx official annual event tables contain 8,164 ex-right/dividend rows. For 5,131 rows with both the event-date quote and prior-session quote in the local daily cache, the prior row's `nextReference` differs from the official event reference by more than NT$0.011 in 1,549 cases (30.2%). The relative difference exceeds 1% in 288 cases, 5% in 61, and 10% in 10; the maximum is 15.23% for 6221 on 2019-10-01 (official reference NT$45.56; prior row `nextReference` NT$52.50). For 5324 on 2020-01-02, the official ex-right reference is NT$9.73 while the prior row says NT$9.80; event-date close is NT$9.71. This is a material source-level mismatch, so the prior-row `nextReference` must not substitute for an absent official event reference. The main engine has been changed to overlay official TWSE/TPEx event references and to treat an uncovered event as unresolved.

Among the 8,559 TWSE daily rows labeled `X` in the cache, 5,348 have an exact-date TWSE official reference and 3,211 do not. Within the 60-stock expanded universe, 13 X rows have no exact-date official reference in the local action inputs. Eleven of those have a prior-session row but no prior close; one (3563 on 2019-04-02) has a prior close of NT$438 and event-day close NT$430; one (6706 on 2019-12-19) has no prior row in the cache. These cases do not establish that no corporate action occurred. The segment policy is appropriate: leave the unresolved event's adjusted values null, start a new segment at the next valid quote, and require a fresh 61-session feature window. Code review confirms `historyRows` passes segment IDs and the portfolio simulator invalidates holdings that cross a null or changed segment; the cohort return is null when invalid.

The official-reference-to-event-close ratio is unusually large on a small number of TWSE X rows. Ten of 5,348 quote/reference pairs differ by more than 10%; examples include 6225 on 2026-08-18 (close NT$48.80 vs reference NT$30.04, +62.45%) and 2429 on 2024-07-02 (NT$42.75 vs NT$29.15, +46.66%). These may reflect substantial actual repricing, but this local audit does not establish the cause. They should remain visible for case-level review and must not be presented as evidence that an action adjustment produced a tradable gain.

## Remaining limits

The cache has substantial TWSE date gaps, both split events in the 60-stock sample are outside covered dates, and 3,211 cached TWSE X rows lack an exact-date reference in the current official reference set. Of the 8,164 TPEx table rows, 2,983 are outside the four-digit research universe; 50 in-universe rows lack a complete event/prior quote pair (including dates outside the price range and individual no-quote observations). These 50 are not an entire-market date coverage gap. A missing row or unexplained X should not be silently converted to zero return or a guessed reference. Price-only reference adjustment also cannot certify cash/dividend reinvestment, suspended-stock exit liquidity, or fillability. No return or strategy conclusion is made in this audit.
