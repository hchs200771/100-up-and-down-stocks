# 選擇權未平倉 P/C 比回測結果（2019-04-11～2026-09-30）

由 `scripts/research-option-pc-ratio.py` 產生，判讀見 [option-pc-ratio-review.md](option-pc-ratio-review.md)。資料：期交所官方「臺指選擇權 Put/Call 比」，以及「三大法人選擇權買賣權分計」的外資及陸資部位（官方只開放近三年，2019 起改用 FinMind 轉載的同一張表）。開發期 2019–2022 有 917 日，樣本外 2023 起有 903 日。

報酬是加權指數對數報酬，從訊號日**次一交易日收盤**起算（保守，避免用到公布前的價格）。控制後係數是把訊號標準化後，迴歸時同時放入過去1/5/20日報酬，單位為每1個標準差對應的基點（bp）；t 值用 Newey–West 調整重疊報酬。18 組比較的 Bonferroni 門檻是 |t| ≥ 3.14。
