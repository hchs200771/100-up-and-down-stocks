# 預設停損與價量分布參考

## 預設停損（使用者 2026-11-13 決定）

持股沒有設定停損時，股票（含融資、美股）一律用：

- 多單：收盤跌破 `進場均價 × 0.90`；空單：收盤站上 `× 1.10`；依跳動單位四捨五入。
- 直接寫入 Notion 持倉的 `停損價` 與 `停損／失效條件`（「預設停損：收盤跌破成本 −10%」），回報時說明是代訂、使用者可改。
- 使用者自己給的停損一律優先，不覆蓋。期貨、選擇權不套用（槓桿不同），維持「待補資料」。
- 融資部位提醒：自備款約四成時，價格跌 10% 約等於自有資金跌 25%。收盤判斷的停損實際平均約賠 12%（跳空、連跌）。

依據：factor-lab `2026-11-13-volume-profile-stop`。新高突破、月線出場下，固定 −10% 每筆 3.35%／2.09%（訓練／驗證），價量停損 3.03%／1.99%，差距不顯著；被洗率固定 −10% 較低（21%／28% vs 33%／35%）。報酬主要來自收盤跌破月線出場（`2026-11-13-ma-exit-length`：15–25 日是平台，20 日沒過度擬合）。

`scripts/holdings-tech-check.ts` 參數帶 `~均價`（例 `7792:多~289.5`）會輸出 `suggestedStopRule: fixed-10` 的預設停損，另附 `volumeProfileStop` 當參考；沒有均價才退回 `fallback-20d`（只當建議，不寫入）。

## 價量分布：參考用

```
npx tsx scripts/volume-profile-stop.ts <代號> <多|空> <均價> [--date YYYY-MM-DD] [--json]
```

用途：看下方支撐（量峰）、上方套牢壓力（第一個量峰當停利參考）、算報酬風險比，判斷 −10% 停損附近有沒有明顯支撐。回測顯示「停損太遠就不進場」與「到第一量峰停利」都沒幫助，不要用它們當規則。

規則摘要：日量攤在高低價間、箱寬 ≥ 均價 1.5%；從均價往下第一個量峰下緣 × 0.9925；超過 10% 改用 10% 內最低的結構價位（未回補跳空起點、波段低點、小量峰）；都沒有就 −10%。

## 範例：安葆（7792）2026-11-12

均價 289.5。使用者已採用價量停損 262（11/10 漲停跳空起點 264 下緣，−9.5%），屬使用者自訂，保留。預設 −10% 會是 260.5。上方第一個量峰從 305 起，報酬風險比約 0.56。
